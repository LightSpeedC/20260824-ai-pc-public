金額の取り扱い

伏せる金額

このリポジトリは公開する前提です。次の金額はドキュメントにも Claude Code の応答にも書きません。

対象扱い
見積金額伏せる 個別に受領した見積の提示額
見積の値引き額伏せる 案件値引きの額、および値引き前後の差額。差額から見積金額が逆算できます
学割金額伏せる 学生・教職員向けストアの価格、割引額、割引率

会話は JSONL に残ります。ファイルから消しても、応答に書けばログに残ります。ファイルと応答の両方が対象です。

書いてよい金額

公開情報として誰でも参照できる金額は、そのまま書きます。

対象扱い
メーカーの掲載価格書く キャンペーンページ・直販ページの価格
定価書く 標準販売価格・希望小売価格
公式ストアの通常価格書く 構成を選択して取得した価格

比較表の基準価格・差額は、伏せた金額ではなく公開情報の価格を基準に組み直します。
