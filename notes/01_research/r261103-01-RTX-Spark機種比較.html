RTX Spark 搭載 PC の比較

NVIDIA RTX Spark (N1X) を積んだ Windows PC を、統合メモリ・帯域・国内価格で並べ、GB10 搭載機と Apple に照らす

📅 作成: 2026-11-03 / 更新: 2026-11-03

RTX Spark とは

NVIDIA と Microsoft が 2026-05-31 に発表した、Windows のノート PC と小型デスクトップ向けの SoC です。Grace CPU (Arm) と Blackwell 世代の RTX GPU を 1 つにまとめ、CPU と GPU が統合メモリを共有します。OS は Windows 11 の Arm 版です。国内では 2026 年 10 月中旬から搭載機が出ています。

N1X 上位 (ノート・デスクトップ)Grace 20コア6,144コア最大 128GB300.8 GB/s45〜80W (デスクトップ 140W)1 PFLOPS
N1X 下位 (ノート)Grace 18コア5,120コア最大 32GB300.8 GB/s45〜80W827 TFLOPS

帯域は NVIDIA の仕様ページに書かれていません。表の値は、仕様ページの 256bit と、各社の資料にある LPDDR5X-9400 から計算したものです (9,400 MT/s × 256bit ÷ 8)。

メモリ構成は CPU/GPU の構成に縛られます。64GB 以上を選べるのは、どの機種も 20コアCPU / 6,144コアGPU の構成だけです。また Microsoft の注記によれば、GPU が使える容量は統合メモリの合計より少なくなります。128GB 機でも、128GB をそのまま GPU で使えるわけではありません。

GB10 搭載機・Apple との比較

128GB 構成どうしで比べます。GB10 搭載機と Apple の価格は、ローカルLLM 機種比較 2026 の 2026-11-03 の値です。

RTX Spark 機は、GB10 搭載機とほぼ同じ価格・同じ帯域のノート PC です。帯域は GB10 搭載機の 273 GB/s より約 1 割広いだけで、Apple の M5 Max (614 GB/s) の半分以下です。LLM の生成速度は帯域でほぼ決まるため、同じモデルなら M5 Max の約半分の速度になる見込みです (実測はしていません)。

128GB を持ち運ぶなら、MacBook Pro 16インチと比べることになります。2TB どうしでは MacBook Pro が 1,209,800 円で、HP・MSI の RTX Spark 機より 8.5〜10.4 万円安く、帯域は 2 倍です。RTX Spark 機を選ぶ理由は、Windows で NVIDIA の GPU を使うことにあります。

GB10 搭載機とは OS が違います。GB10 搭載機は Linux (DGX OS) で CUDA の開発環境がそろった状態で届きますが、RTX Spark 機は Windows 11 の Arm 版です。同じ道具がそのまま動くとは限りません。買う前に、使うソフトが Windows の Arm 版で動くかを確かめてください。
